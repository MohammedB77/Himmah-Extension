# Himmah ✨

**همّة** هي إضافة كروم تساعدك تتابع أهدافك اليومية بطريقة مرتبة وهادئة بعيدًا عن التشتيت.

الإضافة مبنية على مفهوم **SMART Goals Framework** وتركّز بشكل أساسي على عنصر **Time-Bound** بحيث تساعدك تحدد لكل هدف مدة زمنية واضحة مع عداد للأيام المتبقية ونسبة تقدم تساعدك تتابع التزامك بشكل يومي.
---

# ✨ المميزات

- ⏳ عداد للأيام المتبقية لكل هدف
- 📈 نسبة إنجاز تلقائية
- 🎨 تخصيص كامل للألوان
- 💬 اقتباسات تحفيزية عربية
- 🧩 تحريك وترتيب الكروت بحرية
- 🖱️ تغيير حجم الكروت
- 🌌 واجهة هادئة ومريحة للتركيز
- 💾 حفظ تلقائي للإعدادات والأهداف
- ⚡ تجربة خفيفة وسريعة

# ❓ المشكلة

كنت دايم أكتب أهدافي بملاحظات أو تطبيقات ثانية وبعد فترة أنساها أو ما أتابعها بشكل فعلي، خصوصًا من ناحية الوقت والالتزام بالهدف.

وبرضه أغلب تطبيقات الإنتاجية اللي جربتها كانت:
- معقدة
- مليانة أشياء مالها داعي
- وتحتاج تفتح تطبيق كامل عشان تشوف هدف واحد


---

# 📥 تثبيت الإضافة

## 1️⃣ تحميل ملفات المشروع

حمّل ملفات المشروع أو انسخها داخل مجلد جديد.

مثال:

```text
Himmah Extension/
```

ويكون داخله:

```text
manifest.json
script.js
style.css
newtab.html
logo.png
```

---

## 2️⃣ فتح صفحة الإضافات

افتح الرابط التالي داخل Chrome:

```text
chrome://extensions
```

---

## 3️⃣ تشغيل وضع المطور

من أعلى يمين الصفحة فعّل:

```text
Developer mode
```

---

## 4️⃣ إضافة المشروع إلى Chrome

اضغط على:

```text
Load unpacked
```

بعدها اختر مجلد المشروع:

```text
Himmah Extension
```

---

# ⚙️ إعداد Chrome

حتى تشتغل الإضافة بأفضل تجربة:

## 1️⃣ افتح إعدادات Chrome

ادخل على:

```text
chrome://settings/onStartup
```

---

## 2️⃣ اختر

```text
Open a specific page or set of pages
```

---

## 3️⃣ أضف الرابط التالي

```text
https://www.google.com
```

---

# 🚀 تشغيل الإضافة

بعد تثبيت الإضافة:

1. افتح تبويب جديد (New Tab)

2. بتظهر واجهة Himmah مباشرة

3. ابدأ بإضافة أهدافك وتنظيمها

---

# 🎯 طريقة الاستخدام

## ➕ إضافة هدف جديد

تقدر تضيف أي هدف مثل:

- الدراسة
- الجيم
- القراءة
- المشاريع
- تطوير الذات
- تعلم مهارة جديدة

---

## ⏳ عداد الأيام

كل هدف يحتوي على:
- عدد الأيام المتبقية
- تحديث تلقائي يومي

حتى تتابع وقتك بشكل أوضح.

---

## 📈 نسبة الإنجاز

الإضافة تعرض نسبة تقدم تلقائية لكل هدف حتى تقدر تتابع إنجازك باستمرار

---

## 🎨 تخصيص الألوان

تقدر تخصص:
- لون الواجهة
- لون الكروت
- لون النصوص
- لون شريط التقدم

---

## 🖱️ التحكم بالكروت

تقدر:
- تحرك الكروت بحرية
- ترتبها بالطريقة اللي تناسبك
- تغير حجمها بسهولة

---

## 💬 الاقتباسات التحفيزية

الإضافة تعرض اقتباسات عربية تحفيزية تساعدك تحافظ على تركيزك واستمراريتك اليومية.

---

# ⚡ ملاحظات

- الإضافة تحفظ أهدافك وإعداداتك تلقائيًا.
- أماكن الكروت والألوان تبقى محفوظة حتى بعد إغلاق Chrome.
- الإضافة تعمل محليًا بدون الحاجة لأي سيرفر خارجي.
