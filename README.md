# Himmah ✨

إضافة كروم تساعدك تتابع أهدافك اليومية بطريقة مرتبة وهادئة.

تقدر تضيف أهدافك مع:

* ⏳ عداد للأيام المتبقية
* 📈 نسبة إنجاز تلقائية
* 🎨 تخصيص كامل للألوان
* 💬 عبارات تحفيزية
* 🧩 تحريك وترتيب الكروت
* 🌌 واجهة بسيطة ومريحة للتركيز

---

## 📥 التثبيت

## ✨ وش هي Himmah ؟

همّة هي إضافة كروم تساعدك تتابع أهدافك اليومية بطريقة مرتبة وبسيطة.

الإضافة تعطيك:

* ⏳ عداد للأيام المتبقية لكل هدف
* 📈 نسبة إنجاز تلقائية
* 🎨 تخصيص كامل للألوان
* 💬 عبارات تحفيزية
* 🧩 تحريك وترتيب الكروت بحرية
* 🌌 واجهة هادئة ومريحة للتركيز

---

# 📥 طريقة تثبيت الإضافة على Chrome

## 1️⃣ تحميل ملفات الإضافة

حمّل ملفات المشروع أو انسخها داخل مجلد جديد.

مثال:

```text
Himmah Extension/
```

ويكون داخله:

```text
manifest.json
script.js
style.css
newtab.html
logo.png
```

---

## 🌐 فتح إضافات كروم

افتح الرابط التالي داخل Chrome:

```text
chrome://extensions
```

---

## 🛠️ تشغيل وضع المطور

من فوق على اليمين فعل:

```text
Developer mode
```

---

## 📦 إضافة المشروع

اضغط:

```text
Load unpacked
```

بعدها اختر مجلد:

```text
Himmah Extension
```

---

## 🚀 تشغيل الإضافة

بعد الإضافة:

* افتح New Tab
* بتظهر واجهة Himmah مباشرة

---
